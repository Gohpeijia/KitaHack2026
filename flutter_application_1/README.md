# FridgeGuardian 🥬

**KitaHack 2026 — SDG 12.3 (Food Waste Reduction) + SDG 13 (Climate Action)**

FridgeGuardian helps households reduce food waste by scanning fridge contents with AI, tracking expiry dates, and suggesting quick actions to save food before it spoils.

## Features

- **AI-Powered Fridge Scanning** — Take a photo of your fridge, Gemini AI identifies all items with quantity, freshness, and expiry estimates
- **Real-Time Inventory** — Live Firestore-backed inventory with expiry tracking and risk alerts
- **Smart Nudges** — 3 personalized food-saving actions generated by Gemini AI (~15 min each)
- **Impact Dashboard** — Track items saved, CO₂e avoided, and total scans
- **Demo Mode** — Fully offline demo with hardcoded data for instant testing
- **Live Mode** — Real Firebase Auth + Firestore + Storage + Gemini AI integration

## Tech Stack

| Layer    | Technology                                         |
| -------- | -------------------------------------------------- |
| Frontend | Flutter (Dart) — mobile + web                      |
| Auth     | Firebase Authentication (anonymous)                |
| Database | Cloud Firestore (`/users/{uid}/inventory`)         |
| Storage  | Firebase Storage (fridge scan photos)              |
| AI       | Google Gemini 2.5 Flash via `google_generative_ai` |

## Getting Started

### Prerequisites

- [Flutter SDK](https://docs.flutter.dev/get-started/install) (3.11.0+)
- A Google Gemini API key (free): https://aistudio.google.com/apikey

### Setup

1. **Clone the repo**
   ```bash
   git clone https://github.com/your-team/KitaHack2026.git
   cd KitaHack2026/flutter_application_1
   ```

2. **Set up the Gemini API key**
   ```bash
   cp .env.example .env
   ```
   Open `.env` and replace `your-gemini-api-key-here` with your actual Gemini API key.

3. **Install dependencies**
   ```bash
   flutter pub get
   ```

4. **Run the app**
   ```bash
   # Web (recommended for quick testing)
   flutter run -d chrome

   # Android (phone connected via USB)
   flutter run -d android

   # iOS (Mac only)
   flutter run -d ios
   ```

### Demo Mode vs Live Mode

- **Demo Mode (default)** — Works instantly with no setup. Uses hardcoded data to showcase the full user flow.
- **Live Mode** — Toggle "Demo" OFF in the app. Requires a valid Gemini API key in `.env`. Uses real Firebase services and Gemini AI for fridge analysis.

